# Watercolours

Drop the three paintings in this folder with exactly these names (JPG or PNG; if PNG, change the `art:` path in `js/content.js` to `.png`):

- `mehendi.jpg`  — Mehendi & Haldi
- `sangeet.jpg`  — Sangeet
- `wedding.jpg`  — Wedding

Any size is fine. Until a file exists the site shows a coloured placeholder block in its place. Once the files are here, the per-event palettes in `js/content.js` get re-sampled from the paintings.
